## 设计来源

- 动机：哲学 v7 挑战报告挑战三（元系统膨胀）正面回应 + 用户实践感受（harness 文件人读/AI 读双职责冲突）。见 [ADR-0026](../../harness/adr/0026-proj-overview-derived-view-route.md)。
- 路线裁决：**视图派生**而非文件削减——不减文件、不加权威源，只加派生视图层；四个被否决项（文件削减 / 并入 doctor-harness / HTML 优先 / 强同步漂移）见 ADR-0026。
- 设计取向（grill W01 Q6 降格，非可测判据）：「减的负荷 > 加的负荷」；唯一实证锚 = 失忆测试（人判）。

## 关键裁决摘要（选型 14 项全表见 L1「全局选型」节）

- 产物：`harness/PROJECT-OVERVIEW.md`，md + mermaid 单格式（HTML 变体另立 feature 重访）；总长 ≤250 行；五段式；BFS 层次分解图 + DFS 每功能逻辑链（≤30 节点/图，图数 ≤12）。
- 抽象化（W01 Q7）：SKILL.md 只写通用规格（本 skill 即此形态），项目实例清单外置到产物信息源指纹。
- 快照（grill W01 Q2 通用化）：状态追踪文件头部为源（本方法论 = TODO 头部）；AI 不新增判断。
- 文风（W01 Q9）：系统工程术语交集 20 词 + 修辞禁令（「定海神针」类反例）。
- 漂移宽松：不进校验脚本（防第四个提交前检查脚本）。
