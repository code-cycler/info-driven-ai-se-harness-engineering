# ADR-0014:学科挂接策略——分层 + 机制判据

> 状态:accepted(2026-08-10,grill-Q discipline-mapping W01 全 C + 用户补充声明)
> 决策日期:2026-08-10

## 背景

哲学 v4 顶部声明「三学科视角(人因/软工/运筹)」,但压测([grill-discipline-mapping-w01](../questionnaires/archive/methodology/grill-discipline-mapping-w01.md))发现:

- 项目自己的建桥研究(2026-07-28,~/notes)通篇证明实践根植**安全科学**(STAMP/Reason/HRO/Safety-II),canonical 哲学 **0 处承认**——内部文档自相矛盾(D7);
- 大量项目实践(`_vN` / 脱敏门 / ADR / VISION)对应路线图的 CM/QMS/KM/PM/系统工程/认知科学,未在学科层承认(D5 盲点);
- 学科挂接**无判据**(为什么是这 3 个?为什么安全科学不挂?),违反方法论 §2.3「关键决策须给判据」以身作则;
- 挂接缺**形式主义边界**(挂太多 = W01-Q10 所批的「学科单向借术语」)。

## 决策

**1. 分层挂接策略**:
- **哲学正文**:只挂「立论核心学科」——其机制直接支撑方法论核心立论的学科(人因→背景缺失机制、软工→护栏机制、运筹→判断成本机制、安全科学→系统级安全机制)。
- **CONTEXT 学科地图**:承载完整学科全景——实践对应但无立论贡献的学科(系统工程 / 认知科学 / CM / QMS / PM / KM)+ 术语边界注记。

**2. 机制判据**(决定某学科进哲学还是落地图):
> **只挂其机制直接支撑方法论核心立论的学科进哲学;仅实践对应而无立论机制贡献的学科落 CONTEXT 地图。**

**3. 形式主义软边界**:
- 哲学正文学科数 = 「能说出『该学科的哪个机制支撑哪条立论』的学科数」;
- 量化触发:哲学学科数 > 6 时复核是否形式主义([OD-18](../../docs/OPEN-DECISIONS.md) 重访触发③)。

**4. 术语边界**(消除建桥研究 #2 节的混用):
- **安全科学**(Leveson STAMP,安全 = 系统级控制)
- ≠ **可靠性工程**(Reason / HRO,潜伏条件 + 失败预念)
- ≠ **韧性工程**(Hollnagel Safety-II,WAI/WAD 适应)
- 哲学用「安全科学」统领,细节边界落 CONTEXT 地图。

## 替代方案(被否决)

- **只挂 3 核心(现状)**:漏安全科学,D7 矛盾未解。否决。
- **全挂(哲学挂所有相关学科)**:膨胀 + 形式主义,违反 W01-Q10「学科单向借术语」自警。否决。

## 后果

- **正面**:消除「哲学 3 学科 vs 建桥研究安全科学」的内部矛盾;挂接有判据可复核(满足 §2.3 以身作则);防膨胀(软边界 + OD 量化触发);术语精确(三分安全 / 可靠性 / 韧性)。
- **负面**:CONTEXT 学科地图节增加维护成本;哲学立论核心学科中**安全科学的呈现方式待 v5 定**(用户补充声明:开 v5 + 支柱级)。
- **v5 待定**:用户补充声明提议开 philosophy_v5 + 安全科学升**第五学科视角**(2026-08-10 澄清:非支柱,不改双支柱结构)+ 强调去 AI 黑盒——先 grill-with-docs 深钻「去黑盒」立论锚点,结晶后转 design-Q 做 v5(见 [TODO](../../TODO.md))。(2026-08-13 注:「第五学科视角」已更名「**第四学科视角**」,见 [ADR-0015](0015-deblackbox-anchor.md) 更名注记。)
