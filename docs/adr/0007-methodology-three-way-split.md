# ADR-0007: methodology_v3 方法论/哲学/实操三块拆分(结构拆分,非立论演进)

- 日期:2026-08-03
- 状态:accepted
- 来源:design-questionnaire hld 阶段 W00([feature-methodology-separation-hld-w00](../questionnaires/archive/feature-methodology-separation-hld-w00.md)),16 条 15 采纳 + 1 用户先验结论

## 背景

methodology_v3 是单文件混编(哲学/方法论/实操三类内容共存),"改进"任一类别都须动整篇 canonical:改实操(工具链版本、skill 触发时机、工具操作规范)触发 OD-4 母本同步、ADR-0005 四处锁定检查、脱敏门,成本高;且三类内容变更频率差异大(实操高频、方法论中频、哲学低频),混编使高频变更被低频内容的审查纪律拖累。用户诉求:「使得方法论、哲学和实操相互独立,方便改进」。

## 决策

1. **三块独立文件**(`docs/methodology/` 下并列):方法论文件保留 `methodology_v3.md`(版本线继续 v3,本次是结构拆分非立论演进,立论内容不动);新增哲学文件 `philosophy_v1.md`、实操文件 `practical_v1.md`(2026-08-04 压测 Q9 拍板),各 **v1 起线**,独立版本线。导航链接带版本号,版本演进时同步更新。
2. **章节去向**:哲学 = §一(失败模式与信息断层)/ §六(人与 AI 分工)/ 元原则;方法论 = §零/§二/§三/§四/§五/§七 主体(§7.1-7.3/§7.7-7.8)/§九/§十/§十一/§十二/附录 C/附录 D;实操 = 快速上手/§7.4-7.6(上下文管理/层级体系/会话恢复操作链,压测 Q5-B 从 §七 拆出)/§八/附录 A/附录 B。**§二 核心理念保留在方法论文件**(9 处外部引用中 6 处零修改 + 3 处需改,压测 Q1 修正:CONTEXT:15 的 §1.2 → 哲学文件、README:27 的 §8.3 → 实操文件、README:79「完整阐述」表述微调;skill 2 处零修改;方法论保持「独立成文/自包含」)。
3. **canonical 成员扩展**:canonical = 方法论文件 + 哲学文件(方法论主张所在);**实操文件非 canonical**——实操修订走轻量流程(小步 commit、免 OD-4 母本同步、免四处锁定检查),这是「方便改进」的主要兑现。OD-4 表述修订。
4. **License 不变**(ADR-0002 不触发修订):三文件均放 docs/methodology/ 下 → 方法论文字 CC-BY 4.0;实操文件是「文字性使用指南」非 skill 规格,仍属 CC-BY。边界判据:实操手册 ≠ skill 配置,skill 规格内容必须放 skills/(MIT)。
5. **交叉引用**:方法论文件内部 § 引用保留;跨文件引用用相对 Markdown 链接 + 节锚点;CONTEXT/README/skill 外部锚点零修改(§2.1/§5.3 等均在方法论文件)。
6. **一次性拆分执行**:三文件落盘 + v3 文件头标注 + 导航更新(如需)+ 脱敏门 0 命中 + 人审,不攒批次(窗口期成本最低,v3 发布未广泛引用——ADR-0006 先例)。
7. **覆盖上轮候选③**:实操文件补 action-Q 机制论述(确认式问卷 = 非正式行动写操作前对齐细节防幻觉),§4.2 环节详解不展开。

## 替代方案(被否决)

- **单文件分区标注**:不满足相互独立;改实操仍动 canonical 单文件。
- **二文件**(哲学并入方法论或实操):丢三块独立;哲学并方法论 = 现状。
- **§二 移哲学文件**:锚点 9 处全量重写 + 方法论文件失立论根基、「独立成文」破。
- **三文件全升 v4**:混淆 v2→v3 的立论演进语义;v3 发布仅数日。
- **三文件全 canonical**:实操修订触发母本同步,独立改进落空。
- **本次动 skill 文档**:§2.1/§5.3 引用自然有效;「§8.8」是 v2 旧锚点既有漂移(三份引擎副本 QUESTIONNAIRE-FORMAT 引用),另行处置。
- **分批拆分**(先拆实操、后拆哲学):窗口期一次性成本最低;分批引入半拆中间态、两轮审查/两轮脱敏门,收益不抵成本(压测 Q6 补齐)。
- **章节级迁移**(§七 整章留方法论):§7.4-7.6 操作链留在方法论文件会让 skill 家族变化仍扰动 canonical——压测 Q5-B 用户选小节级拆分,「相互独立」承诺在 §七 内完整;代价是章节拆散、§7.x 引用需改造。

## 后果

- (+) 三类内容独立修订:实操高频小步改进不扰动 canonical;哲学/方法论各自演进,改动影响面清晰。
- (+) 外部锚点零修改:CONTEXT/README/CLAUDE/skill 现有「方法论 §」引用全部继续有效(ADR-0006 全量重写先例本次不触发)。
- (+) 「独立成文/自包含」主张保留(方法论文件立论与决策方法自包含)。
- (−) 拆分执行是一次结构性迁移,实现期需核对内容不丢(55 处 § 引用 + 跨文件链接改造:§1.2/§6.x/§8.3/§7.4-7.6 等全量 grep 核对 + 断链检查兜底)。
- (−) 外部引用 3 处需改(CONTEXT:15 的 §1.2、README:27 的 §8.3、README:79 表述),其余 6 处零修改(压测 Q1 修正「锚点零修改」声明)。
- (−) canonical 定义变化(OD-4 修订):「以 methodology_v3 为 canonical」→「方法论+哲学文件为 canonical」,外部读者与未来会话需适应。
- (−) 知识发现:引擎副本 QUESTIONNAIRE-FORMAT ×3 引「方法论 §8.8」为 v2 旧锚点(v3 已无此节),挂 TODO 另行处置。
