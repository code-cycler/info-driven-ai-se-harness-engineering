# ADR-0004: methodology 升 v3——补全「对抗 AI 幻觉式决策」为第一支柱机制层

- 日期:2026-07-29
- 状态:accepted
- 来源:grill-questionnaire 压测 methodology_v2([W01](../../harness/questionnaires/archive/grill-methodology-v2-w01.md)),D7(与作者本意矛盾)核心发现

## 背景

grill-Q W01 压测 methodology_v2 §1.2(信息断层→返工)、§2.1(以信息为核心/有效上下文)、§5.1(Grill 不替决策)的立论连贯性,参照系为作者本意:

> 传统 vibe coding 中**背景信息交代不全** → AI **自以为是、自作主张决策** → **幻觉** → 故方法论采用**问答方式逐步对齐需求**。

压测结论(D7 实质偏离成立,Q9=A;根因 Q9=A):文章用「返工(结果层)+ 有效上下文质量(度量层)」两个**外围框架**,把本意的核心因变量「AI 幻觉式决策(机制层)」挤到了边缘——全文仅 §2.1 一句"不易产生幻觉"带过,无正面因果立论(Q8=A,验收不满足)。根因:v2 写作时为追求"工程化、可度量"的措辞,无意中用温和可量化框架(返工可数、上下文可量 token)替换了尖锐但难量化的本意("AI 自作主张"难量化)。

### 压测产出的细化洞察(写入 v3 立论)

1. **返工的"信息断层"有两类(Q1 ✍️)**——非单一:
   - **人与人之间的断层**:原文 §1.2 写的(等 PM、沟通不一致)——作者承认是"没想到但真实存在"的一类,由 AI 替代角色解决(§6.2)。
   - **人与 AI 之间的断层**:本意(背景交代不全→AI 幻觉),由问答对齐解决(§5)。
   - v3 不能"用幻觉替换返工",而要**区分两类断层**,各自挂到对应解法。
2. **三层立论模型(Q3=A)**:返工=症状层 / 有效上下文质量=度量层 / AI 幻觉式决策=机制层。v3 补全机制层作为根因,前两层挂其下。
3. **(a)/(b) 背景缺失区分(Q5=A, Q6=A)**:(a) 作者知道但没写 / (b) 作者自己也不知道(隐含假设)。(b) 是 AI 幻觉最危险温床(人没说、AI 就编),grill 的不可替代性正在逼出 (b)——这是问答区别于"文档完备主义"的本质。v3 §5.1 应把 grill 锚定到 (b)。
4. **过载≠缺失的对立是伪问题(Q7=B ✍️)**:§2.1"过载"特指**会话内**上下文过长→输出质量下降;对策是「先用 design-Q 等 skill 把决策沉淀落盘 → 再 /compact 压缩」。"缺失(补背景)"与"过载(沉淀+compact)"是**两个不同环节**的操作,不矛盾。v3 §2.1/§7.6 应补这条操作链。
5. **双靶子(Q4=A+C, Q12=A)**:v3 既对照传统多人 SDLC(讲 AI 替代角色),也对照 vibe coding(讲 AI 需纪律约束)——两者是方法论治理的两个极端。vibe coding 进 CONTEXT 为**首要治理对象**,传统 SDLC 退为次要对照。

## 决策

1. **升 methodology_v3**(Q2=A 单向门,Q2.1=b):把「对抗 AI 幻觉式决策」从隐性修饰(§2.1 一句)提升为第一支柱的**显性机制层**立论,作为返工/质量框架的根因。
2. **双靶子叙事**:v3 §零/§1 引入 vibe coding 为首要治理对象,保留传统 SDLC 为次要对照。
3. **CONTEXT 同步**(Q10=A, Q11=A):第一支柱定义补"对抗 AI 幻觉式决策";四术语分层(断层=可见症状 / 流转=过程模型 / 有效上下文=质量度量 / 背景缺失=幻觉根因);新增 vibe coding 术语条目。
4. **正面因果立论**(Q8=A):v3 至少一处明确论证「背景缺失 → AI 在信息真空幻觉式自作主张 → 问答对齐是对抗此机制的直接手段」。

## 替代方案(被否决项)

- **a. v2 原地订正**(不升 v3):否决——偏离非纯"表述不全",是**机制层整层缺失**(Q3=A);且 v2 刚发布(2026-07),订正不足以标记这次立论演进,会让读者误以为 v2 立论本就完整。
- **c. v2 不动,单写「vibe coding 失败模式」专题补充文**:否决——会**分裂 canonical**(方法论第一支柱表述两处不一),违反 [ADR-0001](0001-source-of-truth.md) 单一事实源。

## 后果

- (+) 立论忠实作者本意,机制层补全,返工/质量框架获得根因支撑,读者不再误读成"文档完备主义"(Q5 风险化解)。
- (+) grill 的不可替代性(逼出 (b) 盲区)获得独立立论,问答族 skill 的存在理由更硬。
- (−) v3 是**大改**:牵动 §1.2 / §2.1 / §5.1 / §零 重写,且 CONTEXT.md / README.md / 项目 CLAUDE.md 开篇双支柱表述需同步(防 §7.3 不一致)。
- (−) v2→v3 触发 [OD-4](../OPEN-DECISIONS.md) 母本同步——作者其他位置副本须标注"开发副本,以 v3 为准"。
- (−) 单向门:v3 发布后被引用,旧版(v2)残留不可撤(同 ADR-0003 发布形态逻辑)。
