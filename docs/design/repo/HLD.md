## H1 系统架构(文档体系)

### 1.1 文件分区模型(项目文件 vs harness 依赖文件)

仓库文件分三区(2026-08-05 用户裁决「物理目录分离」):

| 区 | 内容 | 物理位置 |
|---|---|---|
| **项目文件区** | 方法论内容 + 决策记录:methodology/(v4 后含 archive/)、CONTEXT.md、OPEN-DECISIONS.md、adr/、LICENSE | `docs/` |
| **harness 依赖区**(AI 流程产物) | 设计文档套(methodology v3 设计套 + repo 级设计套)、问卷(归档) | 新目录(暂名 `harness/`,最终名 lld 定) |
| **根级入口与产物**(harness 入口,物理不移) | CLAUDE.md / AGENTS.md(新增)/ README / LICENSE / skills/ / scripts/ / .claude/ | 仓库根 |

分区规则:**内容与决策 = 项目文件;AI 流程产物(设计文档、问卷)= harness 文件;执行体与工具 = 根级产物**。CLAUDE.md / AGENTS.md 因工具约定(Claude Code / Codex 自动加载)必须留仓库根,物理不移动,只做职责分类(瘦身 + 路由化)。

**迁移动作**:docs/design/ → harness/design/、docs/questionnaires/ → harness/questionnaires/;涉及引用链接全面改造(lld 列清单)。**skill 落盘路径随迁移同步**(压测 Q1:design-Q / grill-Q / retro-Q 写问卷 + action-Q 归档 + long-running 读归档——5 skill 的 SKILL.md/DESIGN.md 路径字符串 + CLAUDE.md 落盘速查表更新;路径替换是规格同步,skill 行为逻辑不变)。

### 1.2 规范优先级声明

- **位置**:CLAUDE.md「规范优先级」节(会话内必然可见的唯一权威处);README / AGENTS.md 只放链接引用,不复制内容(防漂移,OD-8 教训)。
- **排序**:方法论主张(方法论 + 哲学文件,canonical)> ADR > CONTEXT 术语 > skill 规格(SKILL.md + DESIGN.md 同层)> 实操文件。
- **冲突处理**:按序裁决,且**必须显式说明冲突,不静默选择**(「项目A」L2 优先模式)。
- **协调注(压测 Q12)**:ADR 中的术语定义以 CONTEXT 为准——ADR 记决策(含历史措辞),CONTEXT 记活术语;排序中的「ADR > CONTEXT」指决策裁决,术语定义层 CONTEXT 优先。

### 1.3 入口布局

- **CLAUDE.md**:适度瘦身——方法论摘要压缩指向方法论文件、导航收敛为「规范优先级 + 关键文档导航」两节、状态节保留;不大幅重写(自动加载摘要价值保留)。
- **AGENTS.md**:新增,**零内容路由**(压测 Q10:只放「读 CLAUDE.md + 指向 docs 的链接 + 启动顺序」,不放选读表/清单——双入口零内容 = 零漂移,选读表只在 CLAUDE.md 一处);服务 Codex 收录与 GitHub 规范。
- **README**:「文档入口」表 + 「仓库结构」节按新分区更新。

## H2 技术选型(文档机制)

- **v4 版本机制**:v3 移入 docs/methodology/archive/(沿 v2 先例)+ 方法论/哲学文件头谱系更新(v1→v2→v3→v4 演进链);实操文件不升版。
- **术语治理**:折中审计(保留核心词 / 合并重叠 / 学科可替换优先换)+ 新词引入三条件门槛(学科无对应 + 方法论必需 + 定义清晰);逐词判定表 lld 出;长期全面审计(B 方案)在 TODO。**ADR-0005 四处一致核心子串随替换同步修订**(压测 Q2——术语替换击穿标准措辞与 DoD grep,修订时保留原措辞作历史)。
- **哲学学科化**:章节号保持、节内学科视角显形(Q2 C)。
- **被否决项记录**(防再提议):
  - 哲学章节按学科重组(A 方案)—— 锚点失效,大规模改造
  - 术语激进替换(B 方案)—— 丢失作者原意(v3 立论靠自造词表达,ADR-0004)
  - AGENTS.md 全量单源(「项目A」模式)—— 制造新同步源(本仓库有 ADR/OD-4 体系)
  - docs 目录级重排 / 仅标注归属(「部分重排」)—— 被「物理目录分离」裁决取代
  - 职责分离(不物理移动)—— 用户裁决否决,选物理分离
  - Hallmark pre-emit critique 标记—— 不引入(脱敏门 + 语义人审 + grill-Q 覆盖其功能)

- **CONTEXT = 术语唯一源**:v4 正文术语用词一律对齐 CONTEXT,正文不再各自定义;附录 C 保留演进记录但定义以 CONTEXT 为准。
- **交叉引用格式**:方法论三块 § 互引沿用拆分后约定(17 处跨文件 § 引用改造先例,ADR-0007);harness 区路径变更后的全部链接改造(lld 列清单)。
- **回归工具链**:章节清单(22 项)/ 核心子串 grep(14 项)/ 链接检查(81 个)——v4 落地与迁移后全量重跑。
