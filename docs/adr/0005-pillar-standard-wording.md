# ADR-0005: 第一支柱标准措辞句——四处锁定 + 定义版/完整版拆分

- 日期:2026-07-29
- 状态:accepted
- 来源:grill-Q W01 压测 v3 设计(Q2 立门 + Q12 拆分)

## 背景

[HLD #11](../../harness/design/hld_v1.md) 定第一支柱标准措辞句,v3 §2.1 + CONTEXT + README + CLAUDE 四处原样复用;HLD #14 原判为「lld 落地细节,不立 ADR」。grill-Q W01 压测两点:

- **Q2**:标准句四处锁定 + 对外引用,改一处须同步四处、旧句残留不可撤——锁定效应被低估,满足 ADR 三条件(难逆转 + 会困惑 + 真权衡)。
- **Q12**:标准句含对策「故用问答逐步对齐需求」,原样放进 CONTEXT 违反「纯术语表」规则(grill-with-docs:CONTEXT devoid of implementation details, a glossary and nothing else)。

## 决策

1. **立本 ADR**:第一支柱标准措辞是对外锁定措辞,记录选择与被否决项(修正 HLD #14 的「不立 ADR」判断)。

2. **标准句拆两版**(解 Q12):
   - **完整版**(定义 + 对策)→ 用于 **v3 §2.1 正文**:
     > 第一支柱 · 以信息为核心——与 AI 协作的本质是信息流转;瓶颈不只是有效上下文的质与量,更在于对抗 AI 在信息真空中的幻觉式自作主张决策,故用问答逐步对齐需求。
   - **定义版**(纯定义,删对策)→ 用于 **CONTEXT**(守纯术语表)、**README**、**CLAUDE**(概述性文件):
     > 第一支柱 · 以信息为核心——与 AI 协作的本质是信息流转;瓶颈在有效上下文的质与量,以及对抗 AI 在信息真空中的幻觉式自作主张决策。

3. **"四处一致"重定义**:核心定义部分(「以信息为核心...对抗 AI 在信息真空中的幻觉式自作主张决策」)四处一致,**非字面全同**;对策「故用问答...」只在 v3 §2.1 出现。

## 替代方案(被否决)

- **HLD #11 原「四处原样同一句」**:否——违反 CONTEXT 纯术语表(Q12)。
- **全用定义版**(v3 §2.1 也不含对策):否——v3 §2.1 作为方法论主文需点明「故用问答」的推导闭环。
- **全用完整版**:否——污染 CONTEXT,且 README/CLAUDE 概述性文件塞对策显冗长。

## 后果

- (+) CONTEXT 守住纯术语表;v3 §2.1 保留完整推导;README/CLAUDE 简洁。
- (+) Q8 的 DoD grep 改为匹配**核心定义子串**(「对抗 AI 在信息真空中的幻觉式自作主张决策」,不含对策/加粗),字面匹配更可靠。
- (−) 「四处一致」从字面一致降为**语义一致**,DoD 脚本须匹配核心子串而非全句。
- (−) [HLD #11](../../harness/design/hld_v1.md) 需按本 ADR 修订(进 TODO);LLD #12 DoD 脚本按"核心子串"重写。
