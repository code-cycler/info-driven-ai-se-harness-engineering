# ADR-0003: 发布形态 = 独立完整仓库(文章 + skill + 脱敏示例)

- 日期:2026-07-28
- 状态:accepted
- 来源:建仓前 grill-questionnaire 压测(Q14A)

## 背景

分享「方法论 + skill」有多种形态,默认「独立完整仓库」需给被否决项(方法论 §2.3 自身要求)。形态是单向门:一旦发布 skill,早期版本会被 fork / 引用,迭代后旧版残留。

## 决策

**独立完整仓库**:方法论文章 + 8 个核心方法论 skill + 脱敏后的归档示例。

## 替代方案

- **只发文章**(博客 / Gist / awesome-list),skill 留作「联系获取」:失去「可直接用」核心卖点。
- **文章博客 + skill 精简仓库**(分离关注点):维护两个出口。
- **先发文章探路,再决定 skill**:作为**回退方案**保留——重访触发见 [OD-3](../../docs/OPEN-DECISIONS.md)(若维护精力不足或反响冷淡,退回此形态)。

## 后果

- (+) 价值最完整,差异化最强(方法论 + 可直接运行 skill 执行体一体化)。
- (+) 这是核心方法论 skill 的**首次公开 / 首次版本化**(此前只在作者用户级目录未版本化)——构成仓库独特价值。
- (−) 维护成本最高——靠 README experimental 标注对冲([OD-3](../../docs/OPEN-DECISIONS.md))。
- (−) 单向门:早期 skill 版本被引用后,旧版残留不可撤。
