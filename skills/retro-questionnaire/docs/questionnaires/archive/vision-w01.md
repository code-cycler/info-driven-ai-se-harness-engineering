## Q3. retro 问卷的题型与 design-questionnaire 相同吗?   [落盘: VISION#核心场景]

出题依据:复盘题多为反思题(What went well / wrong),不是决策题——这是两个 skill 的核心差异点,直接影响引擎复用度。

- [X]  A. 同构:仍是选择题 + 🤔 + ✍️,反思题的选项 = 「常见原因假设清单」供快速勾选  ★推荐 —— 引擎零改动复用;假设清单启发思考,真实答案仍走 ✍️ 自定义
- [ ]  B. 异构:retro 以开放式填空为主 —— 复用度低,且填空负担重,违背效率初衷
- [ ]  C. 混合:决策类用选择题,反思类用填空 + 可选假设清单 —— 最贴切,但引擎要扩题型,retro 排期变长
- [ ]  🤔 我定不了 → 推迟/降风险
