# ADR-0017: 哲学独立章节连续化与历史引用兼容

- 状态:accepted(2026-08-14,grill-Q philosophy-v6 W01 Q1 + W02 Q1/Q7)
- 决策日期:2026-08-14

## 背景

哲学 v6 由 `methodology_v3` 拆分而来,正文保留了原章节编号,形成 `§一 → §六 → §七 → §八 → 元原则` 的非连续结构。该做法保护了历史章节语义,但哲学作为独立文章的阅读连续性不足。直接重编号又可能破坏 living 文档链接、Markdown 锚点、ADR 和历史问卷的审计回溯。

## 决策

1. **v7 起采用哲学自身的连续章节编号**,解决独立文章的阅读结构问题;具体章节命名与内容迁移作为后续 canonical 修订执行。
2. **历史产物保持原貌**:已归档问卷、历史 ADR 和历史版本不重写,继续保留其当时的章节语义。
3. **建立兼容层**:新增章节映射、旧章节别名或等价重定向说明; living 文档的引用随迁移更新,并执行断链检查。
4. 本 ADR 只决定版本与兼容策略,不授权直接修改哲学正文;正文修订仍需 canonical 审查与用户授权。

## 替代方案(被否决)

- **永久保留缺号**:迁移成本最低,但独立文章长期像从单文件剪出的章节,与拆分目标冲突。
- **重写全部历史引用与问卷**:表面统一,但破坏历史事实源和从旧压测回溯当前决策的能力。

## 后果

- (+) 哲学 v7 可作为连续、独立的文章阅读。
- (+) 历史问卷、ADR 与旧版本仍可按原编号审计,兼容关系可重建。
- (−) v7 需要维护一次映射与兼容锚点,并同步 living 文档引用。
- (−) v6 归档版本仍保留非连续编号;当前 v7 通过映射与兼容说明承接其历史语义,不改写历史事实源。
