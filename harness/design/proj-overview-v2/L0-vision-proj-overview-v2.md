## 核心场景

1. **失迷失忆恢复**:隔 ≥3 天切入,走导读三分钟档(定位 + 状态快照 + 决策脉络)恢复掌控。
2. **定期重定向**:项目演进后重生成视图,刷新心智模型。
3. **复杂项目信息传递**:多层次多功能关系图两遍展开(BFS/DFS)。
4. **新人首次全面理解项目** ★新增:走十五分钟档(+ 结构全景 + summary 表浏览)建立完整框架。

## 验收标准(可独立验证条目式)

1. **失忆测试**(核心锚,原三问式保留):窗口自 **v2 生成日 ≥3 天重算**(v1 的 09-28 预约作废);只读视图 ≤15 分钟答三问(当前主线 / 关键决策所在文件 / 下一步);三问全达 = 过、两达 = 部分过记回评;结果回写 skills/proj-overview/DESIGN.md「dogfood 修订」节。
2. **dogfood**:v2 重生成本身即 dogfood 载体 + 用户「掌控感/完整度」主观反馈记 DESIGN.md。
3. **规格符合性**:8 项职责齐;所有图 TD 且 subgraph 无 `direction LR`;ADR 表行数 = ADR 实数(26)、OD 表行数 = OD 实数(28);每条 summary 行带源文件相对链接;叙述段 ≤ 15 行;**超源即删自检执行**(逐段溯源,指不出源的段落删除,自检结果留痕)。
4. **skill 本体元成本**:SKILL.md < 100 行。
5. **治理联动**:ADR-0026 修订注记;skill CHANGELOG v2 条目(仅项目侧);skills-sync-check 双侧 0 违规;en/skills/proj-overview/SKILL.md 回译 + `--stamp`;挑战报告反馈行注记。
6. **TODO 观察项登记**:新人视角测试不升级为正式验收,记 TODO(重访触发 = 失忆测试通过后评估);+ 规模重访触发(grill W01 Q6:ADR>50 或视图>800 行 → 评估年代折叠——近 N 条全量 + 旧条年代行)。

## 风险与约束

1. **误导风险升级**(summary 面扩大):每条 ADR/OD 行带源链接(点击核对)+ summary 段头部置顶警示行(「以源文件为准,禁止按过期 summary 做单向门决策」)。
2. **膨胀风险**(无行数上限):对策 = 派生性质即约束 + 超源即删自检——行数是源文件面的函数,不是生成时自由变量。
3. **阅读负荷风险**(文件变长后 15 分钟测试可能超时):对策 = 导读三档读法,三分钟档必须覆盖失忆三问答案。
4. **自指风险**(skill 本体膨胀):<100 行硬约束守住,summary 细则进设计套/DESIGN.md 不进 SKILL.md。
5. **漂移风险**:宽松漂移守住;强化自声明 = 文件头信息源清单按 summary 段分列源文件 + 段级「截至」时点。

## 动机

- **用户对 v1 的两不满**(2026-09-25):① mermaid 横向排列可读性差(subgraph 内 LR + DFS 全 LR,规格空白致生成时自选);② 内容不足以「任何开发者一篇完整掌握项目」,要求承担 ADR/OD/TODO 等 harness 文件 summary 职责。
