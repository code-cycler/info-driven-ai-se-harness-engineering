## 目标与受众

- **feature 一句话目标**(W00 #1):为仓库建立「中文 canonical + 英文镜像」的 i18n 支持——中文为唯一权威源,英文以顶级 `en/` 文件夹镜像派生并受漂移治理(结构失配 / 过期 / 链接三类可检出),服务英文读者理解并引用方法论体系。
- **服务对象定标**(W00 #2):英文镜像第一受众 = 潜在**英文采用者 / 方法论读者**(分发展示:能读懂方法论、能导航到任一文档、能引用)。「让英文用户全量**运行** 8 个 skill 工作流」默认 = 范围外(运行级 = 每 skill 双语言执行体,工程量 ×2 且与「中文是唯一生产车间」相悖;英文用户如要运行按需手动适配)。〔readme-revamp「第一受众 = 潜在采用者」类比 + 用户「首选语言中文」〕
- **canonical 方向(单向)**(W00 #3):中文 = 唯一权威源;英文 = 单向派生的镜像,**英文永不回灌中文**(反向不成立);中文每次修订 → 对应英文镜像进入「待翻译 / 过期」状态。同步语义 = 结构镜像 + 源指纹检出 + 人驱动回译,**非自动机械改写**。

## 范围(做什么;明确不做什么)

**做**:
1. 顶级 `en/` 镜像树(布局见 L1):镜像对外消费内容——根 README、根 CHANGELOG(对外变更记录)、docs/(CONTEXT / OPEN-DECISIONS / methodology current 三件 + practical_v1 / retro)、skills/ 各 SKILL.md(规则本体的英文说明),文件级一一对映;
2. 漂移治理机制:独立 `scripts/i18n-check.py`(结构镜像存在性 + 源指纹过期 + 链接三类检查),提交前与 skills-sync-check.py 并联跑(机制方向,细节契约 L1);
3. 术语一致:英文术语单点落位(CONTEXT 英文列,与哲学「术语中英文并置」先例一致);
4. 语言切换入口 + canonical 声明 + License 继承声明(细节契约 L1)。

**明确不做**:
- **内部治理产物不翻**(W00 #4,#5,#6):harness/ 全部(ADR / design 层文件 / 归档问卷 / STATUS-LOG)、TODO.md、CLAUDE.md、AGENTS.md、scripts/ 三个 py(?脚本输出 / docstring)、waste/。理由:内部产物是「AI 生产车间」+ 历史事实,无英文读者、归档问卷/ADR 不可译(历史记录),且每次演进都同步 = 超额漂移成本;「范围全仓库」应解读为「全对外门面」。
- **archive/ 历史文档不翻首期**(W00 #6):docs/methodology/archive/ 六件(约 3,012 行历史母本)与 philosophy archive 首期排除,只镜像 current/canonical 三件 + practical_v1;archive 是否纳入英文镜像留 **L1 定**(不预设)。
- **镜像粒度 = 文件级**,不做到段级(W00 #7):段落级 = 翻译记忆库工程,首期不值;W01 可重访更细粒度(注:L0 未转 W01,粒度重访权限留 L1)。

## 核心场景

1. **场景一 · 英文读者到达**(W00 #8):英文开发者到 GitHub → 从根 README 顶部语言切换链接进入 `en/README.md` → 读英文方法论三件 → 理解双支柱与体系 → 深读 8 个 skill 英文 SKILL.md → 引用 / 试用。**验收:en/ 根为可导航入口,从根可达任一镜像文件。**
2. **场景二 · 中文演进 → 过期检出**(漂移治理核心场景,W00 #9):中文某文件修订 → 漂移检测器报「该文件源已变、英文镜像过期」→ 人 / agent 安排回译 → 回译后镜像的同步标记更新 → 再检变净。**验收:实测改一处中文,检测器即报「过期」。**
3. **场景三 · 结构失配检出**(W00 #10):中文新增可翻文件 → en 缺镜像 = 违规;中文删除文件 → en 孤儿(无中文源)= 违规。检测器两类都报。**验收:i18n-check 对「缺镜像」与「孤儿」分别报出。**
4. **场景四 · 链接与占位符一致**(W00 验收③④):译本内链接互指 en 目标、中文原文相对链接重写;占位符(「项目X」)保持不误译。

## 验收标准(可独立验证条目式)

**验收主集七条**(W00 #19):
- ① **结构镜像完整**:`python3 scripts/i18n-check.py` 对每一「可翻文件」报「缺镜像」为 0(全部有一一对映 en);
- ② **无孤儿 en**:同脚本「无中文源」报为 0;
- ③ **en 内链接全通**:提取 en/ 全部相对链接逐条核通(含锚点);
- ④ **脱敏**:`python3 scripts/desensitize.py .` 0 命中(英文镜像占位符如「项目X」保持一致,不误译);
- ⑤ **既有合规不破**:`python3 scripts/skills-sync-check.py` 仍 0 违规(经 #13 隔离,英文镜像不入扫描面);
- ⑥ **过期检出可演示**:实测改一处中文源 → i18n-check 报「中文已变、英文过期」;
- ⑦ **首期翻译面覆盖完成**(见下 #20 清单)。

**首期翻译面(交付范围,不追一次翻全)**(W00 #20):首期 = 门面与核心 = 根 README + docs/methodology current 三件(methodology_v5 / philosophy_v7 / practical_v1)+ docs/CONTEXT + docs/OPEN-DECISIONS + 8 个 skill 的 SKILL.md + 根 CHANGELOG 现条目。**架构(目录/检查器/术语/工作流)一次到位,翻译分步推进**——首期之后的覆盖面(OD 全量 / archive / retro 等)由后续迭代补,不在首次交付承诺。理由:全库 2.36 万行一次翻完 = 超长尾、必然中途漂移;先定机制再滚量。

## 风险与约束

**风险登记**(W00 #21):
- ① **双写 / 漂移**(本 feature 的核心对抗对象——中文演进后英文静默过期)→ 对策 = 独立检查器 + 提交前门(强制跑验收 ①–⑦);
- ② **术语不一致**(各文件自行英译)→ 对策 = CONTEXT 单点英文术语列;
- ③ **链接重写错**(en 内互链指错)→ 对策 = 验收③链接检查;
- ④ **占位符 / 脱敏误译**(「项目X」被当普通词译掉)→ 对策 = 译文占位符保持原文 + 验收④;
- ⑤ **工程量**(2.36 万行)→ 对策 = 分步首期(#20)。

**既有已决项重访(显式留痕)**(W00 #22):readme-revamp「不做英文 README(列为未来可选项)」已决项([L0-vision-readme-first-impression.md:22](../../harness/design/readme-revamp/L0-vision-readme-first-impression.md) + 归档问卷要点 12)——本次 i18n 立项 = 该未来可选项触发条件满足,**正式推翻该决、执行英文镜像**,并在两处留痕:① `harness/design/readme-revamp/L0-vision-readme-first-impression.md` 该行加重访注记;② 根 CHANGELOG 记一条「i18n 立项 = 重访 readme-revamp 英文 README 决项」。不得静默执行。(留痕动作随本 feature 执行期落,验收含此二处。)

**价值排序**(W00 #23):漂移治理(不腐坏)> 术语一致 > 覆盖全面 > 译文润色;首期使命 = **立起可复跑的治理机制 + 门面译文**,不追求一次翻全。

## 动机

用户发起(2026-08-22):「本仓库 i18n 支持:首选语言中文、支持英语、单独文件夹治理、与中文同步、重点关注漂移治理,接轨既有漂移治理资产(铁律 8 / OD-8 / OD-24 / ADR-0024 / skills-sync-check),范围全仓库,镜像翻译」。现状核实:全库纯中文唯一主语言,无任何 i18n 基础设施;英文仅存在于 3 处非主面(grill-with-docs 的 SKILL.md + 三个格式文件、waste/skills/grill/、个别 frontmatter description)。readme-revamp 曾决「不做英文 README(列为未来可选项,外部反馈出现需求时再议)」——本次立项即触发该「未来可选项」的重访(W00 #22)。

## 待定 / 移交 L1 的事项(W00 #20 分步 + #7 重访权限 + #6 archive 判定)
