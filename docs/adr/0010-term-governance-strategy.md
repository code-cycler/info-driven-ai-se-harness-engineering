# ADR-0010: 术语治理策略(折中审计 + 新词三条件门槛)

- 日期:2026-08-05
- 状态:accepted
- 来源:repo 级设计(vision W01 Q4 自定义「重点是规范术语,不随意造新词」+ hld W01 Q4 方向)+ grill-Q 压测回灌(Q2 ADR-0005 子串核查)

## 背景

方法论第一支柱有 8 个术语(信息断层 / 信息流转 / 有效上下文 / 背景缺失 / 信息真空 / 机制层·度量层·症状层 / vibe coding / (a)(b) 盲区),多为自造词。用户要求「规范术语,不随意造新词」,优化方向指向人因工程 / 软件工程 / 运筹学学科对接。存量处置与新增门槛需定。

## 决策

1. **折中审计(本次)**:逐词判定,**8 术语全部保留**——核心术语均有作者特有语义结构(如 (a)(b) 盲区的两类区分、背景缺失的 (a)(b) 从属),学科标准词无法无损替换(人因「情境意识」/「信息加工缺陷」语义相关但无精确对应)。判定表(术语 × 学科参照 × 判定 × 理由)落 CONTEXT「术语治理」节。
2. **学科参照注记**:每个术语标注学科参照(信息断层 → 人因信息加工缺陷 / 有效上下文 → 认知负荷 / 背景缺失 → 情境意识等),为哲学文件学科化(ADR-0008)提供衔接。
3. **新词引入三条件门槛**(后续新增术语必过):① 学科标准词无对应;② 方法论必需(无法用现有词表达);③ 定义清晰(落 CONTEXT 判定表或正文首次定义处)。
4. **ADR-0005 核查**:无词替换 → 「四处一致」核心子串不变,ADR-0005 无需修订。
5. **长期全面审计(B 方案)**:逐术语重新判定 + CONTEXT 重写 + 全文同步,记入 TODO,待折中审计运行观察后执行。

## 替代方案

- **只设新词门槛,存量不动**:存量膨胀问题不解决(「信息真空 = 背景缺失别名」这类语义重叠仍存在)。否决。
- **全面审计重写(本次即做)**:术语变更波及方法论全文 + 8 skill 规格 + 归档问卷,同步成本高;且核心词的作者原意(v3 立论靠自造词表达,ADR-0004)有丢失风险。否决(用户 W01 Q4:本次先折中,长期选 B 进 TODO)。
- **激进学科替换**:能挂学科概念的全换——丢失作者特有区分,与 v3 立论(ADR-0004)兼容性风险。否决。

## 后果

- (+) 术语体系稳定:8 术语全保留,学科参照注记提供对外对话接口;新词膨胀被门槛遏制。
- (+) ADR-0005 四处一致检查不受影响,DoD 子串无需变更。
- (−) 「信息真空」与「背景缺失」语义重叠未合并(合并将改写 ADR-0005 核心子串,成本 > 收益),留长期审计候选。
- (−) 学科化效果依赖哲学文件(§一 人因视角等)的论述质量,术语本身未换词。
