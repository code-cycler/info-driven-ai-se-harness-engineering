# ADR-0018: 哲学 / 方法论双文件交叉挑战治理

- 状态:accepted(2026-08-14,grill-Q philosophy-v6 W02 Q10)
- 决策日期:2026-08-14

## 背景

三文件拆分降低了实操修订对 canonical 的影响,但哲学与方法论都承载方法论主张,若各自独立演进而没有相互挑战,仍可能发生论证、边界和操作契约漂移。用户提出将治理焦点收窄到哲学与方法论,但并未要求删除既有实操资产。

## 决策

1. **canonical 对等双文件**:哲学文件与方法论文件作为两份 canonical 成员,各自拥有独立版本线,不要求版本号锁步。
2. **交叉挑战门**:任一 canonical 文件发生修订时,另一份文件必须完成交叉审查或 grill-Q 一致性检查,至少核对变更类型、主张边界、跨文件引用、唯一权威、受影响 skill、方法不变量、验证状态、证据强度、已知缺口、影响范围和回退 / 重访条件。
3. **实操文件保留**:`practical_v1.md` 继续作为非 canonical 操作指南,承载工具时机、执行细节与上下文操作链;本 ADR 不删除、合并或重命名它。
4. **证据留痕**:交叉审查结果进入对应问卷处理报告、ADR / OD 或 TODO;“已交叉审查”不等于哲学主张或下游效果已经验证。

### 补充裁决(2026-08-14,grill-Q philosophy-v7 W01 Q10)

「方法论文件自包含」限定为**可独立执行流程与操作规范**:读者不应为了执行关键步骤而必须回到哲学文件。哲学文件负责动机、失败模式、责任边界与不可裁剪原则;方法论文件可以链接哲学解释「为什么」,但不得把关键执行步骤藏在哲学中。此判据纳入后续双文件交叉审查记录。

### 最小记录字段(2026-08-14,grill-Q philosophy-v7 W01 Q8 / W02 Q10)

每次 canonical 修订至少留下以下记录:变更类型;受影响主张、引用和 skill;唯一权威;是否改变方法不变量或不可逆治理边界;两份 canonical 文件各自的审查入口;证据状态与 assurance 强度;已知缺口;回退 / 重访条件;用户确认;当前、已提交、已发布状态。记录模板见 [方法论治理最小切片](../design/methodology-governance/LLD.md)。

## 替代方案(被否决)

- **物理合并实操文件**:减少文件数量,但会把高频操作变化重新带入 canonical,并触发迁移与重复成本。
- **三文件继续各自独立且只保留普通链接**:成本低,但不足以防止两份核心主张互相漂移。
- **三文件版本锁步**:表面统一,但违背哲学与方法论内容变化频率不同的拆分初衷。

## 后果

- (+) 哲学与方法论可以独立演进,又有强制的相互挑战点。
- (+) 实操资产继续保留,不把操作细节重新塞回 canonical。
- (−) 每次 canonical 修订增加一次交叉审查成本;需用最小检查清单控制形式主义。
- (−) 双文件交叉审查具体清单仍需首轮试运行后校准,不能把审查存在本身当作效果证据。
