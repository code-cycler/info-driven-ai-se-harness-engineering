# 解析与落盘规则(design-questionnaire 引擎 · 复用件)

> ⚠️ 本文件是 design-questionnaire 引擎的**第 4 份副本**(2026-07-30 从 design-Q canonical 复制)。design-Q 为 canonical;另有 retro-questionnaire、grill-questionnaire、action-questionnaire(本)共四份。修改需考量四方同步,漂移需声明(见四处 DESIGN.md)。
> **本 skill 的有意分叉**(2026-07-30 grill-Q W01 Q3/Q4/Q7 裁决,OD-11):
> 1. **小波阈值 ≤ 4**(design-Q 为 ≤ 2)——经验估值,双向门,待真实使用数据校准(理由见 DESIGN.md Q3)。
> 2. W00 解析语义:勾选 = **确认理解正确**(按理解执行),留空 = **理解有误/要改**(转深究);与 design-Q「采纳默认/不采纳」对应但措辞随 confirm-list 改。
> 3. 落盘无阶段文档(无 VISION/HLD/LLD):常规留痕 = 归档问卷;三条件升格 ADR/OD/CONTEXT 照常。
> 4. 补充声明第四类「**用户先验结论 → 待验证假设**」(2026-07-31 dogfood D-1 回修,仅本副本;canonical 跟进与否由 design-Q 上下文另决——2026-07-31 用户小波裁决「只改 action-Q」)。

## 解析

用户宣布「答完了」之后:

1. 问卷 status:`pending` → `answered`。
2. 逐题读取勾选状态与自定义文本,按下表处理异常:
3. 阅读「补充声明」区(必读),内容按类型处理:新需求 → 下一波或修订理解;答案补遗 → 按映射落盘;格式反馈 → 修订 QUESTIONNAIRE-FORMAT.md;**用户先验结论 → 列为待验证假设,分析/处理中显式检验,不预设为结论(防确认沦为给用户先验背书),处理报告标注**。所有去向写入处理报告。

| 异常 | 处理 |
|---|---|
| 单选题勾了多个 | 记冲突,不猜;列入处理报告,进下一波问卷澄清(标注「上轮冲突」) |
| 必答题未勾且无自定义 | 列入处理报告「未答」区,下一波重出该题(标注「上轮未答」) |
| 非必答题未答 | 视为跳过,记录,不重出 |
| 条件子问题条件不满足但被答 | 忽略该答案,处理报告中记录 |
| 自定义文本模糊或引出新分支 | 进下一波追问(标注出处) |
| 对话速答中「不知道/不确定/你决定/推迟/看你」 | 视同勾了 🤔 逃生舱,走降风险协议 |

**confirm-list 解析(每次确认 W00)**:勾选 `[x]` = 确认理解正确 → 按 AI 的理解执行,处理报告逐条标注「来源 = W00 确认」;留空 `[ ]` = 理解有误或要改 → 转 W01 正式题深究,或**正式题数 ≤ 4 时小波直接问**(不生成问卷文件);W00 无 🤔(对/不对二选一,不对即留空);W00 全部勾选(全确认)合法,处理报告仍列确认清单;W00 确认与 W01 正式题答案冲突时,以 W01 为准并在处理报告记录冲突。

## 落盘映射

所有落盘**本波处理完即刻执行**,不批处理。目标文件不存在时懒创建;命名沿用项目既有约定(如 `_vN` 版本规则)。

| 答案类型 | 落盘目标 |
|---|---|
| 确认结果(常规) | 问卷归档(`harness/questionnaires/archive/`,只移不删)为唯一常规留痕 |
| 术语定义类 | CONTEXT.md(纯术语表,不放决策与实现细节) |
| 满足 ADR 三条件的决策 | docs/adr/NNNN-<slug>.md(编号顺延现有)。**确认中揪出的决策照常记录,不因「非正式行动」而免记** |
| 🤔 逃生舱(单向门) | docs/OPEN-DECISIONS.md |
| 🤔 逃生舱(双向门) | 采用 ★推荐项 **且进 OD 标注**(标「双向门 / 采用推荐项 X / provisional」+ 重访触发条件)。采用推荐项也留痕——2026-07-24 design-Q dogfood 补充声明(逃生舱采用推荐项也要进 OD,信息不丢失优先) |
| 行动项(处理报告产出) | `<项目根>/TODO.md`(问题 → 行动 → 核验时机;懒创建) |

ADR 三条件(缺一不写):难逆转 + 缺上下文会让人困惑 + 经过真实权衡。

## 降风险协议(逃生舱触发时)

1. **判可逆**:双向门(命名、内部结构、默认值、配置项)→ 采用 ★推荐项,**同时进 OD 标注**(记录「采用推荐项 + 双向门 + 重访触发条件」),告诉用户改起来便宜。采用推荐项也留痕——2026-07-24 design-Q dogfood 补充声明。
2. **推迟或缩小**(单向门):能整个推迟 → 进 OD;能先定最小可逆切片 → 定切片,不可逆部分进 OD。找最可逆的占位方案,并向用户用大白话解释各选项利弊(顺便填知识缺口)。
3. **最后手段**(必须现在定且不可逆):给明确推荐 + 推理过程 + 可逆性评估(改主意的代价、什么信号出现时应重新审视),用户角色降级为「否决或接受」,进 OD 并标 provisional。
4. **OD 条目必填字段**:问题、推迟原因(知识缺口 / 经验缺口 / 无法预判)、当前占位方案、可逆性、**重访触发条件**(具体信号,禁止「以后再说」)。

## 预勾设防(opt-in 开关开启时适用,2026-08-03 起)

预勾开关(用户启动本 skill 时明确说「预勾选」)开启时,防默认效应退化为确认仪式:

1. **取消默认率指标**:每波处理报告必带「取消默认率」(取消预勾数 / 预勾总数)。
2. **落盘前显式确认点**:处理报告必须列「默认采纳清单」(未人工修改、按默认落盘的条目),用户确认前不得落盘——确认点在处理报告输出与落盘之间。
3. **连续 3 波零取消 → 警告 + 建议回退**:连续 3 波「取消默认率 = 0」且无自定义修改 → 警告「预勾可能已退化为仪式」,建议关闭开关或复核问卷质量。
4. **单向门题防护**:单向门题若以默认状态落盘(异常),落盘前显式确认时强制逐条复核;复核不通过不得落盘。

开关关闭(默认)时:无预勾、无取消率概念,本节不适用。

## 处理报告(每波必出,对话内输出)

```markdown
## 处理报告 · confirm-<slug> W<NN>

- 落盘:Q1 → 归档;Q3 → docs/adr/NNNN-xxx.md ……
- 新增/更新文件:<列表>
- 异常:Q5 单选多勾 → 进 W02 澄清;Q7 必答未答 → W02 重出
- 逃生舱:Q4 判双向门 → 采用推荐项 B;Q8 单向门 → OD 条目,触发条件「……」
- confirm-list 统计(仅 W00):确认正确 X / 留空纠正 Y / 转正式题或小波 N(无 🤔 项)
- 下一波候选:<引出的新问题 / 深分支>
- 覆盖度:隐式骨架六要素(目标/输入/输出/约束/边界/依赖)确认 X/6;动态盲点剩 N 个
```

## 归档

1. 处理报告输出且用户无异议 → 问卷 status:`processed` → `archived`,移入 `harness/questionnaires/archive/`,文件名不变。
2. 归档前在文件尾部追加处理报告摘要(落盘文件链接列表);**行动完成后把执行结果摘要一并追加**,保证单文件可回溯。
3. 只移不删。
4. 提问波(≤4 题,未生成问卷文件)的问答与处理摘要,追加到最近一份归档问卷尾部,标注「提问波」。
