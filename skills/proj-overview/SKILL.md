为「人读」生成项目掌控视图——**认读第一入口:人重载上下文从此开始**。harness 文件面向 AI 重建上下文(严谨详细),本产物面向人(认知友好)——只读派生,行数随源文件面线性增长,生成禁止自由发挥。

## 定位与边界

- 横切工具型:不进 5 环节闭环主路径;纯生成,无问卷无 AskUserQuestion。
- 产物 = 单份只读派生视图:不新增权威源、不参与规范优先级裁决、**以源文件为准**;三入口各有侧重、允许重叠(CLAUDE.md 偏 AI 会话 / README 偏对外采用 / 本文件偏人的全面掌握)。
- 治理文件 summary = 只读派生转述:**不承接源文件活职责**(行动追踪/变更记录/状态史仍归 TODO/CHANGELOG/STATUS-LOG);源文件更新后 summary 即过期。
- 不做五文件既有职责;禁止按过期视图或过期 summary 做单向门决策(发布/删除/花钱/脱敏前必回源文件核对)。

## 主流程四步

1. **扫描(分级读取,禁全仓深读)**:结构类全读(README / CLAUDE.md / 目录树);治理类 = CONTEXT 节标题 / 设计套索引**头读** + **ADR/OD 全量条目读**(每条标题 + 状态/决策节首段,支撑一行摘要);关键 N 份选读(承载当前主线,从状态追踪文件与近期变更反推)。
2. **抽取**:节点两类(功能/结构、信息/工件);边三类(包含、依赖、流转·触发)。当前状态快照 = 项目状态追踪文件头部(遵循本方法论时 = TODO.md 头部)**直接引用转述,AI 不新增判断**;无此惯例以 git 近况为准并标注数据源;头部与 git 近况明显不一致 → 提示人先更新,AI 不代写。
3. **组织:八段固定序** ① 定位(一句话 + 三入口侧重)→ ② 导读(三档读法)→ ③ 结构全景(BFS 总图 + 区块索引表)→ ④ 治理文件 summary → ⑤ 决策脉络(关键决策时间线)→ ⑥ 当前状态快照 → ⑦ DFS 深链 → ⑧ 检索索引(「我想找 X → 去 Y」按问题组织)。
4. **渲染**:md + mermaid 代码块;图内用短名/编号,链接统一放图旁索引表(markdown 相对链接,文件级为主、关键链到「文件#节」锚点)。

## 输出规格(硬约束)

- 落点 `harness/PROJECT-OVERVIEW.md`;手动触发、覆盖式重生成(git 历史即版本)。
- 文件头三件套:时间戳 + 信息源清单(按 summary 段分列源文件,路径+每文件一行摘要)+「以源文件为准,本文件为派生视图;认读第一入口」声明。
- **导读段 3–5 行,三档各一行指段号**:3 分钟恢复(①⑥⑤)/ 15 分钟框架(前四段 + summary 表浏览)/ 检索(⑧⑦ + 图旁索引)。
- **summary 段规格**(段头置顶警示行「以源文件为准,禁止按过期 summary 做单向门决策」):ADR 表 3 列(编号·带源链接 / 标题 / 一句话决策摘要——取材 = 「决策」节首句直引或紧缩转述,**禁跨节综合**;生成时抽 3 条人快审);OD 表 3 列(编号·带源链接 / 主题 / 状态——**直读 OD 状态字段,禁 AI 归纳**;无该字段的项目直引标题门型标注);TODO/STATUS-LOG/CHANGELOG 头部用叙述 + bullet;**每表行数 = 源条目实数**。
- **图规格**:所有图 `flowchart TD`(竖向),subgraph 内**禁** `direction LR`;BFS 一张层次分解图(≤30 节点,超限按层聚合);DFS 动态选取 = 主线链 1 条(生成时承载当前主线者,自指合法深度 1)+ 高风险/挂账链 1–2 条 + 刚收口链可选 1 条,共 3–5 条,每图 ≤30 节点;图数 ≥2 且 ≤12。
- **行数不设硬上限**(派生性质即约束);**分型自检**:事实段(summary/快照/脉络)逐段溯源到文件,结构段(定位/导读/索引)核段规格;叙述段目标 ≤15 行。
- 漂移宽松:不进校验脚本、无强制同步义务;新鲜度靠文件头三件套自声明。

## 人因设计原则

- 信息分层:披露顺序 = 概览 → 读法 → 结构 → 治理资产 → 演变 → 状态 → 链路 → 检索(新人通读递进;失忆快路径由导读承载)。
- 渐进披露三级:概览层无链接 → 结构层索引表 → 链路层「文件#节」锚点。
- 图规模 ≤30 节点/图;线性认知顺序(八段固定序不重排)。
- 学科锚:认知负荷、情境意识(引 CONTEXT 既有定义,不新造术语)。

## 文风规范

- 禁令:比喻性代称(「定海神针」类)、文学修辞、情绪化形容。
- 术语表(系统工程通用交集,不引用单一标准):模块 / 接口 / 依赖 / 基线 / 追溯性 / 验证 / 配置项 / 职责 / 边界 / 约束 / 入口 / 流转 / 状态 / 快照 / 层级 / 覆盖 / 偏差 / 裁决 / 触发 / 交付。

## 触发与自检

- 触发词见 frontmatter;每次触发 = 全量重生成(覆盖式)。
- 生成后自检(一次性,不立常驻脚本):八段标题 grep 齐;`direction LR` 0 命中;summary 表行数 = 源目录实数(生成时实测 N 作注记);每条 summary 行含相对链接;分型自检与 ADR 摘要抽审留痕(DESIGN.md);**逐图渲染验证**——临时 HTML(mermaid CDN)浏览器验证后删。
- 失忆测试由人执行(非 skill 内置):隔 ≥3 天只读视图,≤15 分钟答三问(当前主线 / 关键决策所在文件 / 下一步),全达 = 通过(三分钟导读档应覆盖三问)。
