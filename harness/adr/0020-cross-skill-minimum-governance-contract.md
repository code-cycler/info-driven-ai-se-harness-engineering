# ADR-0020: 跨 skill 最小治理契约

- 状态:accepted(2026-08-14,grill-Q philosophy-v7 W02 Q1/Q2/Q10)
- 决策日期:2026-08-14

## 背景

当前 skill 家族已有九个入口,其职责边界大体清晰,但输入、输出、决策权、证据状态和交接条件分散在各自规格中。若直接新增一个总控 skill,会把尚未证实的协作缺口固化为第十个入口;若完全依靠链接,则核心治理要求容易漂移。

## 决策

1. **暂不新增跨 skill 总控 skill**。保留九个入口,先验证协作契约是否真的不足。
2. **为每个 skill 建立最小生态位卡**:输入、输出、决策权、禁止越界、相邻 skill 的交接条件。**载体裁定(2026-08-14,grill-Q methodology-improvement W01 Q9)**:生态位卡以 [methodology_v5 §3.3.1](../../docs/methodology/methodology_v5.md) 路由表行承载(表行五字段即卡),唯一权威 = §4.3.1(与 OD-22 一致),不另建 per-skill 实体卡;若 dogfood 出现「查表不能替代查卡」的真实场景,重访本条。
3. **只为四项不可裁剪核心和高风险路径建立最小覆盖矩阵**:责任 skill、最小产物、当前状态、缺口;其余哲学主张保留文档级链接,不建立全量句子追踪矩阵。
4. **跨 skill 共同契约至少包含**:输入/输出、证据状态、偏差记录、验证强度、交接触发。
5. **先用一个真实案例完整 dogfood**。只有契约重复失败且集中治理收益明确时,才重新评估新增入口。

## 替代方案(被否决)

- **立即新增统一治理 skill**:入口统一,但新增权威层、迁移成本和单点拥塞尚未有实证必要性。
- **建立全量哲学主张追踪矩阵**:覆盖最强,但会把哲学变成高维护的规格索引,证据成本不与风险匹配。
- **完全保持 skill 独立**:组织最简单,但无法稳定承载 W01/W02 已确认的共同底线。

## 后果

- (+) 先解决路由可见性和关键风险覆盖,不以合并入口掩盖边界问题。
- (+) 将证据成本集中到判断权、单向门、L3 独立验证和冲突恢复等真正改变安全边界的主张。
- (−) 生态位卡、覆盖矩阵和共同契约需要维护,且首个真实案例可能暴露新的边界问题。
- (−) 在 dogfood 完成前,不能宣称九个 skill 已形成可验证的统一治理层。

## 重访条件

满足任一条件时重访“是否新增统一治理入口”:两个独立真实案例出现重复交接歧义或重复归属冲突;高风险缺口找不到责任 skill;契约自身持续漂移;或一次完整 dogfood 仍无法产生可追溯交接记录。
