# ADR-0001: 本仓库是方法论与 skill 的唯一 source of truth

- 日期:2026-07-28
- 状态:accepted
- 来源:建仓前 grill-questionnaire 压测(Q1A + Q1.1A)

## 背景

本方法论与 skill 家族在建仓前分散在多处:skill 定义在作者用户级目录(从未进版本控制);方法论文章与部分 skill 副本、归档问卷曾在作者的另一个公开项目(harness 引擎)中出现过(含未脱敏的项目名)。现要为本方法论 + skill 建立独立、脱敏的公开仓库。定位是发布前最难逆转的决策,且直接关系到多副本漂移(skill 家族此前已有 ≥3 份副本)。

## 决策

1. **本仓库是「方法论文章 + skill 家族」的唯一 source of truth(canonical)**。
2. 其他位置(用户级目录、另一个公开项目)的 skill 副本、归档问卷、文章副本,视为**私有 / 历史开发副本**,不作公开口径。
3. 另一个公开项目里已存在的那 2 个 skill 定义 + 归档问卷**保留不动**(历史不可逆),README 注明「作者另有早期未脱敏副本」,诚实告知。

## 替代方案

- **并行多官方**:接受多副本漂移。否决——违反方法论自身「引擎漂移」失败模式警告。
- **塞进现有 harness 项目**:混淆该项目「harness 引擎」定位。否决。
- **fork 标注衍生**:与「脱敏解耦」目标冲突。否决。

## 后果

- (+) 单一事实源,根治多副本漂移。
- (+) 独立品牌,脱敏边界干净。
- (−) 另一项目已公开的未脱敏副本无法撤回,靠 README 注明对冲。
