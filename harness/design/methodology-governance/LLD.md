## L2 首批方法不变量与验证卡

### 验证卡共同字段

每张卡必须记录:稳定 ID、主张、适用范围、当前状态、违反症状、反例、最小独立证据、代理指标(如有)、例外边界、唯一权威、失效信号、重访条件、最近验证记录、**模型行为假设**(主张成立依赖的模型行为前提——与「失效信号」配对构成公理租约;前提失效时重访本卡。2026-08-18,grill-Q first-principles W01 Q2)。

### 首批卡片

| ID | 主张 / 不变量 | 适用范围 | 最小独立证据 | 例外边界与重访 |
|---|---|---|---|---|
| `MC-01` | 信息断层 → AI 自作主张的主张必须区分事实、假定与未验证项;未验证的高风险动作不得继续 | 需求、设计、工具或外部依赖信息不完整时 | 原始资料或可复现命令/输出;处理记录标出未验证状态;低风险与高风险分流可重建 | 纯探索性低风险动作可带状态继续;出现错误假定导致返工时重访 |
| `MC-02` | 判断性决策与最终确认由人承担,AI 只能在批准边界内执行 | 目标、风险、验收、接口或不可逆状态可能改变时 | 决策记录与人工确认;无法分类时按判断性决策处理 | 纯执行白名单可下放;白名单、权限或边界变化时重访 |

当前四张卡均为**目标治理能力 / 未验证**。首轮案例完成后,逐卡填写证据入口;若证据不足,保持未验证或进入“疑似失效 → 暂停采用 → 已知缺口 / 临时占位 → 恢复验证”。

**首批模型行为假设注记**(2026-08-18,grill-Q first-principles W01 Q2):MC-01 依赖「背景缺失时 AI 不主动声明不确定性、以最合理猜测补全」(当前代际行为观察,非结构性真理——模型默认输出置信度时失效);MC-02 / MC-03 依赖「AI 自评可靠性低于人审」(AI 自评与人审一致率数据反超时重访);MC-04 无模型行为依赖(纯流程约定)。

## L5 首轮 dogfood 与 DoD

1. 选择一个真实、低风险且可回退的功能或治理改动,按唯一 skill 路由表选择入口。
2. 在 design-Q → grill-Q → dogfood / 测试 → long-running → retro 过程中,记录每次交接的输入、输出、证据状态、偏差和下一入口。
3. 用 `MC-01` 至 `MC-04` 逐卡填写最小证据;至少制造或复盘一个边界 / 失败场景。
4. 对 delegate 若启用,仅使用 1–2 类低风险、可逆、可计数决策,完成一次收回 / 全局关闭故障演练。
5. retro 只允许三种结论:证据支持、保持未验证 / 临时占位、发现失效并进入恢复路径;不得用文档存在替代验证。

DoD:路由可追溯;四项核心均有责任 skill 和最小产物;四张卡各有证据入口或明确缺口;交叉审查记录完整;脱敏与 harness-check 通过。未完成首轮 dogfood 前,本切片状态保持“目标治理能力 / 未验证”。
