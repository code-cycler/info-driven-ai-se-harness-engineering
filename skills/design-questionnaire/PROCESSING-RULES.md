# 解析与落盘规则(design-questionnaire 引擎 · 复用件)

> 本文件与 [QUESTIONNAIRE-FORMAT.md](./QUESTIONNAIRE-FORMAT.md) 共同构成问卷引擎。后续 skill(如 retro-questionnaire)复用这两个文件,只换自己的骨架模板。

## 解析

用户宣布「答完了」之后:

1. 问卷 status:`pending` → `answered`。
2. 逐题读取勾选状态与自定义文本,按下表处理异常:
3. 阅读「补充声明」区(必读),内容按类型处理:新需求 → 下一波或修订规格;答案补遗 → 按映射落盘;格式反馈 → 修订 QUESTIONNAIRE-FORMAT.md。所有去向写入处理报告。

| 异常 | 处理 |
|---|---|
| 单选题勾了多个 | 记冲突,不猜;列入处理报告,进下一波问卷澄清(标注「上轮冲突」) |
| 骨架必答题未勾且无自定义 | 列入处理报告「未答」区,下一波重出该题(标注「上轮未答」) |
| 非必答题未答 | 视为跳过,记录,不重出 |
| 条件子问题条件不满足但被答 | 忽略该答案,处理报告中记录 |
| 自定义文本模糊或引出新分支 | 进下一波追问(标注出处) |
| 对话速答中「不知道/不确定/你决定/推迟/看你」 | 视同勾了 🤔 逃生舱,走降风险协议 |

**白名单包确认题解析(delegate 接口触发时,2026-08-20)**:整包确认 → 白名单内决策按所列值落盘(落盘目标 = 对应层文档/常规映射,另在处理报告列「白名单自动决策清单」+ 逐例追加 `delegation-log.md`);逐条挑出 → 挑出项作正式题深究,其余按值落盘;整包否决 → 全部转正式题,当波不自动决策。挑出/否决事实记入 delegation-log(留「人收回」痕迹)。

**preview 解析(每阶段 W00)**:opt-in 开关开启时:保持预勾 `[x]` = 采纳默认 → 按 AI 默认倾向落盘,处理报告逐条标注「来源 = W00 预答」;取消勾选(留空)= 不采纳 → 转入 W01 作为正式题逐个深究(当波 W01 不足时进下一波);**单向门要点必须人显式勾选,处理时逐条复核非默认状态**;W00 全部保持预勾(全采纳)合法,处理报告仍列预答清单(并计入取消率,见「预勾设防」);W00 预答与 W01 正式题答案冲突时,以 W01 为准并在处理报告记录冲突。开关关闭(默认)时:全部 `[ ]` 人逐条作答,无取消率概念。

## 落盘映射

所有落盘**本波处理完即刻执行**,不批处理。目标文件不存在时懒创建;命名沿用项目既有约定(如 `_vN` 版本规则)。

| 答案类型 | 落盘目标 |
|---|---|
| L0-vision 层题(旧名 vision,别名) | `harness/design/` 的 `L0-<功能>.md` |
| L1-contract 层题(旧名 hld,别名) | `harness/design/` 的 `L1-<功能>.md` |
| L2-build 层题(旧名 lld,别名) | `harness/design/` 的 `L2-<功能>.md` |
| 自声明层(L1+ 任意)题 | `harness/design/` 的 `L<N>-<功能>.md`(命名见 STAGE-SKELETONS 总则) |

旧三件命名(VISION/HLD/LLD)**仅存量文件豁免**;新产物一律 LN 制(2026-08-20 同步修,grill-design-q-w01 Q1-B)。
| 术语定义类 | CONTEXT.md(项目固有,路径不动;纯术语表,不放决策与实现细节) |
| 满足 ADR 三条件的决策 | `harness/adr/NNNN-<slug>.md`(编号顺延现有) |
| 🤔 逃生舱(单向门) | OPEN-DECISIONS.md(项目固有,路径不动) |
| 🤔 逃生舱(双向门) | 采用 ★推荐项 **且进 OD 标注**(标「双向门 / 采用推荐项 X / provisional」+ 重访触发条件)。采用推荐项也留痕,不再「不进 OD」——2026-07-24 dogfood 补充声明(逃生舱采用推荐项也要进 OD,信息不丢失优先) |
| 行动项(处理报告 / 复盘产出) | `<项目根>/TODO.md`(项目固有,路径不动;问题 → 行动 → 核验时机;懒创建) |

ADR 三条件(缺一不写):难逆转 + 缺上下文会让人困惑 + 经过真实权衡。

## 降风险协议(逃生舱触发时)

1. **判可逆**:双向门(命名、内部结构、默认值、配置项)→ 采用 ★推荐项,**同时进 OD 标注**(记录「采用推荐项 + 双向门 + 重访触发条件」),告诉用户改起来便宜。采用推荐项也留痕——2026-07-24 dogfood 补充声明。
2. **推迟或缩小**(单向门):能整个推迟 → 进 OD;能先定最小可逆切片 → 定切片,不可逆部分进 OD。找最可逆的占位方案,并向用户用大白话解释各选项利弊(顺便填知识缺口)。
3. **最后手段**(必须现在定且不可逆):给明确推荐 + 推理过程 + 可逆性评估(改主意的代价、什么信号出现时应重新审视),用户角色降级为「否决或接受」,进 OD 并标 provisional。
4. **OD 条目必填字段**:问题、推迟原因(知识缺口 / 经验缺口 / 无法预判)、当前占位方案、可逆性、**重访触发条件**(具体信号,禁止「以后再说」)。

## 预勾设防(opt-in 开关开启时适用,2026-08-03 起)

预勾开关(用户启动本 skill 时明确说「预勾选」)开启时,防默认效应退化为确认仪式:

1. **取消默认率指标**:每波处理报告必带「取消默认率」(取消预勾数 / 预勾总数);W00 与 W01+ 分别统计。
2. **落盘前显式确认点**:处理报告必须列「默认采纳清单」(未人工修改、按默认落盘的条目),用户确认前不得落盘——确认点在处理报告输出与落盘之间。
3. **连续 3 波零取消 → 警告 + 建议回退**:连续 3 波「取消默认率 = 0」且无自定义修改 → 警告「预勾可能已退化为仪式」,建议关闭开关或复核问卷质量。
4. **单向门题防护**:单向门题若以默认状态落盘(异常),落盘前显式确认时强制逐条复核;复核不通过不得落盘。

开关关闭(默认)时:预勾设防不适用,但**质量信号仍观测**(2026-08-20,grill-design-q-w01 Q4-A):每波 W00 处理报告统计「**全采纳率**(勾选采纳数 / 要点总数)」;连续 ≥3 波全采纳 → 处理报告提示「可能疲劳顺勾,建议复核要点质量」。边界:此为护栏观测(防默认效应,对齐第二支柱「无护栏 → 产出悄悄劣化」),**不做机制价值统计**(取消率/转 W01 数等 W00 形态验证类统计不采——2026-08-20 grill-design-q-w01 Q6-C 裁决,防混用)。

## 处理报告(每波必出,对话内输出)

```markdown
## 处理报告 · <stage> W<NN>

- 落盘:Q1 → VISION.md#核心场景;Q3 → harness/adr/0018-xxx.md ……
- 新增/更新文件:<列表>
- 异常:Q5 单选多勾 → 进 W02 澄清;Q7 必答未答 → W02 重出
- 逃生舱:Q4 判双向门 → 采用推荐项 B;Q8 单向门 → OD 条目,触发条件「……」
- preview 统计(仅 W00):勾选采纳 X / 留空不采纳 Y / 转正式题 N(无 🤔 项)
- 预勾统计(opt-in 开关开启时):默认采纳 X 条(取消默认率 Y%)/ 单向门显式确认 N 条 / 默认采纳清单已列,待确认
- 下一波候选:<引出的新问题 / 深分支>
- 本阶段覆盖度:骨架 X/Y 项已覆盖;动态盲点剩 N 个
```

## 归档

1. 处理报告输出且用户无异议 → 问卷 status:`processed` → `archived`,移入 `harness/questionnaires/archive/`,文件名不变。
2. 归档前在文件尾部追加**处理报告全文**(每题去向 / 异常 / 逃生舱处置 / 下一波候选 / 覆盖度),顶部保留摘要节(落盘文件链接列表速览)——「原始信息不丢失」覆盖解析产物(决策的「为什么」),跨会话恢复(回退协议重开层 / long-running 反推)依赖此留存(2026-08-20,grill-design-q-w01 Q9-A)。
3. 只移不删。
4. 提问波(≤3 题,未生成问卷文件;上限 3 = 2026-08-08 用户裁决,原 ≤2)的问答与处理摘要,追加到最近一份归档问卷尾部,标注「提问波」。
